# Task 62 C0 and C1

This package freezes the prospective Task 62 hybrid reporting evaluation and materializes twelve deterministic content contracts, twelve deterministic comparator reports, and a thirty six call plan.

The language model is restricted to one qualitative executive summary with no digits. All facts, numbers, citations, interpretations, uncertainties, refusals, identity fields, and authority language remain deterministic.

Run from the repository root:

```bat
call scripts\run_task62_c0_c1_v425.bat
```

No API call is made in C0 or C1.
