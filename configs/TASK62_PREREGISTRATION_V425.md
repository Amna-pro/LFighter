# Task 62 preregistration

Task 62 prospectively evaluates a hybrid forensic reporting architecture motivated by the frozen Task 61 failure diagnostic.

The deterministic stage selects and locks all four observed facts, every numeric value, citations, interpretations, uncertainties, refusals, identity fields, and the authority statement. The language model produces only a short qualitative executive summary containing no digits. The final report is assembled deterministically.

The primary automated hypothesis is that all final hybrid reports preserve the locked content exactly and achieve repeat numeric consistency of 1.0 across three retained repetitions per case.

Human superiority is not claimed unless at least two independent blinded reviewers complete the preregistered comparison. The first repeat is selected prospectively for human review. No best output selection is permitted.

No training, new SHAP evaluation, security decision, or reserved test array access is permitted.
